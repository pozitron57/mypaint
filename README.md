# MyPaint для онлайн-уроков — личный форк

MyPaint используется как доска с графическим планшетом на macOS.
Рабочий код находится в ветке
**[`codex/teaching-board`](https://github.com/pozitron57/mypaint/tree/codex/teaching-board)**.

Отличия от оригинала:

- горячие клавиши работают при переключении между латинской и русской раскладками;
- панели только по Tab (курсор около края экрана не открывает меню);
- вставка по горячей клавише использует текущее положение курсора;
- меню MyPaint доступно в системной строке меню macOS;
- в полноэкранном режиме скрывается выезжающий заголовок окна с кнопками;
- плавное перемещение и масштабирование трекпадом замедлены в четыре раза;
- сохранены две небольшие правки совместимости с установленным PyGObject.
